## Что должно заработать

Оркестратор обычного прогона на Claude Code читает `phases/4-plan.md` и `phases/5-subagents.md` без разделов чужих режимов; каждый режим находит свой текст по строке-указателю; тест не даёт обычному пути снова разрастись.

## Из брифа, дословно

> «Из `phases/4-plan.md` и `phases/5-subagents.md` в отдельные файлы выносится то, что обычному прогону на Claude Code не нужно: строгий режим и регистрация агентов, Opus, Codex, `--sequential-host`, контроллер, изолированные таски. Каждый такой файл читается только в своём режиме; в основном остаётся строка «в режиме X читай Y».»
> «Это перенос, не редактура. Таблица «Reading this skill» в `SKILL.md` обновлена.»
> «Тест-ограничитель: сумма байт файлов обычного пути (перечень в тесте) не больше порога. Порог — фактический размер после переноса плюс 5 %; цель — не больше 110 КБ. Цель не достигнута переносом — в отчёте фактическое число, текст ради цифры не режется.»
> «Тест: каждый вынесенный файл упомянут в основном файле своей фазы.»
> «Три README и `docs/autopilot/` поправлены там, где ссылаются на перенесённое.»
> «Ни одно правило навыка не теряется при переносе текста.»
> «R06 и R05 оба меняют `phases/5-subagents.md`: сначала R05, потом перенос.»

Полный текст — раздел R06 и разделы 1, 4, 5 в файле брифа.

## Разделы спецификации

История R06; «Вне рамок». Оглавление двух файлов с пометками, что относится к какому режиму, и список тестов, которые ищут фразы, — `notes.md` §6 (номера строк могли сдвинуться после тасков 01 и 02: сверяй по заголовкам).

## Критерии приёмки

- [ ] Разделы про строгий режим и регистрацию агентов, Opus, Codex, `--sequential-host`, контроллер, изолированные таски вынесены из `4-plan.md` и `5-subagents.md` в отдельные файлы `phases/`; на месте каждого — одна строка «в режиме X читай Y»
- [ ] Тест: каждый вынесенный абзац дословно присутствует в новом файле (сверка с версией файлов до таска), ни одна строка правил не пропала
- [ ] Тест: каждый вынесенный файл упомянут в основном файле своей фазы; таблица «Reading this skill» в `SKILL.md` называет новые файлы
- [ ] Тест-ограничитель: сумма байт файлов обычного пути (перечень в тесте) не больше фактического размера после переноса плюс 5 %; текст ради цифры не сокращён
- [ ] Три README (деревья файлов), `docs/autopilot/` и `docs/adr/0002` (ссылка на раздел вместо номера строки) поправлены; тесты, искавшие фразы в старых местах, ищут их в новых и зелёные
- [ ] Раздел «After each ticket» из таска 02 не изменён переносом; ничего из раздела 4 брифа не сделано; в этой сборке сделаны только волны 1–3

## Возврат оркестратору

В отчёте назови фактическую сумму байт обычного пути до и после и порог теста.
