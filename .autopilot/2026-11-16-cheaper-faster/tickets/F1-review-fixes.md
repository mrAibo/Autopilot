## Критерии приёмки (находки ревью, дословно)

- [ ] `skills/autopilot/SKILL.md:6` (allowed-tools): маски `Bash(python *tools/ap.py* bootstrap *)` и `... doctor*` начинаются с `python *`, так что `python -c "<код>" x/tools/ap.py doctor` проходит без вопроса, как и любой чужой `tools/ap.py`. Условие: маска не пускает ничего, кроме запуска самого ap.py; нужен якорь вида `python "<путь>/tools/ap.py" bootstrap ...` без свободных `*` перед `tools/` (или без `-c`/`-m` и аргументов до пути), и тест `test_skill_allowed_tools.py` должен падать на примере с `-c`; сейчас его регэксп `tools/ap\.py\* (bootstrap|doctor)` ширину не ловит. Если формат масок не позволяет закрепить путь без свободной звёздочки — маски для `bootstrap` и `doctor` из папки навыка убираются совсем (будет запрос разрешения), и это сказано одной строкой в `phases/0-instruments.md`.
- [ ] `skills/autopilot/tools/ap.py` (`cmd_numbers`, `blind` круг 2): зелёный G4 при оставшихся расхождениях — проверена только верхняя граница `checked <= len(mismatches_r1)+1`, нижней нет. Воспроизведение: круг 1 `checked=8 matched=5` и три `--mismatch`, круг 2 `checked=0 matched=0` (или `checked=1 matched=1`) без `--mismatch` → итог `checked=8 matched=8 mismatches=[]`, G4 зелёный. Условие: в круге 2 `checked >= len(расхождений круга 1)`; каждое расхождение круга 1 либо закрыто, либо остаётся в `mismatches`; иначе отказ без записи. Тесты на оба воспроизведения.
- [ ] `skills/autopilot/phases/5-subagents.md`, раздел «After each ticket»: возвращена потерянная при переписывании мысль прежнего текста — один коммит на таск это точки отката пользователя; трейлеры `Autopilot-Run` (папка прогона без `--wip`) и `Requirements` делают историю искомой (`git log --grep="R02"`). Одна-две строки, раздел остаётся короче прежнего.
