# Границы, решённые в спецификации

## Правила проекта (из «Договорились» PROGRESS.md — связывают спецификацию)
- Ключ подписи гейтов вне проекта (`~/.autopilot/gate.key`), признак «прогон начат подписанным» — в `$AUTOPILOT_HOME/runs/`.
- Opus — только по подтверждению пользователя; Fable не допускается ни под каким написанием.
- Возврат упавшего таска и сдача с отказами — только цитатой пользователя (`reset --by-user`, `finish --by-user`).
- «и не забудь вставлять в дешборд наш лого» — логотип остаётся в шапке и рейке.
- «Обзор» и «Компактный» — по макетам; «Классика» держит старые цвета; остальные темы в новой палитре как есть.
- Жёсткий минимум Claude Code 2.1.295; ниже 2.1.311 — предупреждение.
- Только стандартная библиотека Python; `state.js` читается и пишется только через `state_io.py`.
- Исполнители коммитят `git commit --only <файлы зоны>`, без `git stash`.

## Единицы

**ap.py · пути и сервер** — владеет путями файлов прогона и сервером дашборда.
- `ticket_files(state, pattern) -> list[str]` — единственная точка поиска файлов тасков; внутри `glob.glob(os.path.join(glob.escape(run_dir(state)), "tickets", pattern))`. Все 8 мест вызова ходят через неё.
- Сервер: свой обработчик `http.server`. Отказ 403, если `Host` не `127.0.0.1:<порт>`/`localhost:<порт>`, если `Sec-Fetch-Site: cross-site`, или если к `state.js` и любым данным, кроме самой страницы и статики, нет `?t=<токен>`. Токен случайный, хранится в `.autopilot/serve.token` (в `.gitignore` вместе с `serve.*`); адрес, который печатает `ap.py`, содержит `?t=`; страница передаёт токен при загрузке `state.js`. Открытие `file://` токена не требует (данные внутри снимка).
- Снимок дашборда пишется через `state_io.replace_with_retry`.

**ap.py · этапы** — этап хранит `segments: [{startedAt, finishedAt|null}]`; `cmd_stage` при возврате этапа открывает новый отрезок и закрывает прежний; `startedAt/finishedAt` остаются как первый старт и последний конец (обратная совместимость). Минуты этапа = сумма отрезков; нет `segments` — как раньше.

**ap.py · лента гейтов** — запись сброса: `{"reason": "plan-changed", "g": "G1|G2|G4"}`; дашборд рисует её отдельной строкой «Проверка сброшена: план изменился», в карточке гейтов — «сброшена».

**ap.py · история сборок** — `state.history: [{dir, title, startedAt, finishedAt, minutes, tickets, repairs, tokens, result}]` собирает `ap.py` из архивных `state.js` и `run-log.jsonl` прошлых прогонов (не более 20, свежие первыми; битый файл пропускается). Шаблон только рисует.

**ap.py · расход** — `state.spend: {byRole, byModel, byTicket}` из `run-log.jsonl`; строки без модели — «не указана». `state.logFailures: int` — число сбоев записи журнала.

**run_log.py / claude_attest.py · расход** — строка `executor` получает поля `model`, `effort` (из профиля субагента `.claude/agents/<agent_type>.md`, иначе из `resolvedModel` аттестации, иначе пусто). `append` по-прежнему не бросает; при сбое записи увеличивает счётчик в `.autopilot/run-log.fail` (число), который `ap.py` отражает в `state.logFailures`.

**model_router.py · риск и классы** — `assess_ticket(text)` считает риск по зоне и целым словам: максимальный риск — только если зона таска включает чувствительные пути (`claude_agent_guard`, `gate_sign`, `model_router`, `state_io`, авторизация, платежи, миграции, ключи/секреты) либо слова из `RISK_RE` встречаются в тексте таска, чья зона содержит код; таск, чья зона — только `*.md` и `docs/`, получает риск 0. Подстроки (`auth`, `session`, `migration`) — только по границе слова. Планировщик может записать в таск `**Класс:** механический|обычный|сложный` и `**Причина класса:** …`; роутер принимает класс как оценку (механический → баллы cheap, сложный → strong), но не опускает ниже рассчитанного по зоне. Сигнатуры `choose_route` и `assess_ticket` не меняются.

**model_router.py · профили** — `cheap` делится: `cheap_read` (`haiku/low`, разведчик) и `cheap_code` (`haiku/high`, исполнитель механического таска). Запрет Fable и Opus без подтверждения не ослабляется.

**retry_policy.py · эскалация** — после первого дозапроса красной проверки у таска на Haiku допускается ровно одна эскалация Haiku → Sonnet (`ticket NN retry --cause tests --escalate`), она записывается в таск и видна на дашборде («начат на Haiku, доделан на Sonnet»). `docs/autopilot/retry-policy.md` обновляется: правило «не повышать» остаётся для остальных случаев.

**gate_sign.py** — запись «прогон начат подписанным» через временный файл и `replace_with_retry`. Ключ: на Windows защищён DPAPI (`ctypes`; `gate.key` содержит блок с префиксом `dpapi:`), на остальных ОС как сейчас; старый незащищённый `gate.key` читается и переписывается защищённым. `bash_gate` в `claude_agent_guard.py` запрещает субагенту команды, чьи аргументы затрагивают `.autopilot/`, `~/.autopilot/`, `.claude/agents/` (запись, удаление, копирование, перенос), на любой ОС.

**dashboard-template.html · страница по умолчанию** — новый вид `now` (первый в `VIEW_IDS`): вкладки «Сейчас · Требования · Итог · Подробности»; «Сейчас» подбирает содержимое по состоянию (ждёт ответа — закреплённая полоса вопроса сверху; идёт разработка — доска тасков; сдано — итог). Старые восемь тем остаются в переключателе под «Ещё». Узкая раскладка включается по ширине окна. Логотип в шапке и рейке сохраняется. «Подробности» — модели, расход, проверки, история сборок.
- Доска тасков: «Ждёт · Пишется · Проверяется · Сдан»; упавший таск — красная карточка сверху с причиной; возврат с ревью — «возвращён ×N»; на карточке номер, название, требования, модель, таймер, попытки, строка «почему ждёт / что сказало ревью».
- Доска требований: «Разбирается → В плане → Делается → Проверяется → Принято» плюс полоса «Нужны твои данные · Отложено · Снято»; переключатель «по требованиям / по таскам».
- Боковая панель таска по клику: что делать, требования, зона, модель и причина человеческими словами, лента событий, тесты, коммит, замечания ревью.
- Язык: служебные строки (`score=…; profile=…`) переводятся функцией `humanRoute(route)`; коды G1–G4 не в основном тексте.
- Ждёт ответа: уведомление браузера (после явного разрешения кнопкой), значок на вкладке, закреплённая полоса с текстом вопроса и временем ожидания.
- Мелкие правки: у сданной сборки «сдано <время>» вместо «обновлено N назад»; счётчик повторов в «Классике» у любого таска; `role="listitem"` у этапов.

**Документы** — `phases/4-plan.md` (класс таска от планировщика; «Haiku-таски» по признакам: одна зона, до ~150 строк, критерии — команды, интерфейсы записаны; не дробить мельче порога холодного старта), `phases/3-spec.md` (разведчик пишет «пакет контекста» `context-pack.md` для исполнителя), `docs/autopilot/*` (model-routing, retry-policy, run-log), три README, `AGENTS.md`.

**report-run** — по каждой модели: число тасков, доля сданных с первого раза, число починок, токены на таск; журнал без модели — «не указана».

**Счётчик тестов** — скрипт `tools/test_count.py` печатает число тестов `unittest`; `AGENTS.md` и README берут число из него между маркерами `<!-- tests:count -->`.

## Швы для тестов
`ap.py` на пути с `[` и пробелом; сервер — запросы с неверным `Host` и без токена; `cmd_stage` при возврате этапа; `assess_ticket` на тексте с «author»/«подписи» в зоне `.md`; `run_log.append` с model/effort; `gate_sign` — запись и DPAPI-ветка (на не-Windows пропуск); строки шаблона дашборда — тестами по образцу существующих в `tests/`.
