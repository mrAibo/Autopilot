## Критерии приёмки

- [ ] «Подробности» показывают `state.spend`: токены по ролям, по моделям, по таскам («сколько стоил этот таск»); без данных — «ещё нет» с одной строкой причины (журнал не вёлся или модель не записана); строки без модели — «не указана»
- [ ] Сравнение с прошлыми сборками: длительность, число тасков и починок, расход этой сборки рядом со средним по `state.history`; без прошлых сборок блока сравнения нет
- [ ] Лента прошлых сборок из `state.history`: название, длительность, число тасков и починок, расход, итог; до 20 строк; пустая история — «прошлых сборок ещё нет»
- [ ] Вкладка «Ресурсы» сданной сборки и «Подробности» не показывают «Токены — ещё нет», когда в журнале есть строки расхода (воспроизвести на фикстуре из 38 строк)
- [ ] Бейдж «журнал неполный: N строк не записано» при `state.logFailures > 0` в «Подробностях» и в шапке «Сейчас»; при 0 бейджа нет
- [ ] Таск с `escalatedFrom` подписан «начат на Haiku, доделан на Sonnet» на карточке доски и в панели таска (модель из `escalatedFrom` и текущая)
- [ ] Тесты на шаблон для всех состояний (пусто, данные, неполный журнал, эскалация); никаких «undefined» и «NaN»; `python -m unittest discover -s tests` зелёный
