## Что должно заработать

Исполнителю после красной проверки и ревью возвращается одно сводное сообщение; оркестратор находит замолчавших агентов; в worktree зависимости копируются копией, где это безопасно. После `finish` собираются уроки и профиль проекта, а следующий `init` и исполнители их читают.

## Из брифа, дословно

> «Стадии «проверки» и «ревью ветки» идут одновременно; исполнителю возвращается всё одним сообщением: упавшие тесты и замечания. Исполнитель запускает только тесты своих изменений, полный набор гоняет `ticket NN land` или `tools/run-tests.py`.»

> «Агента останавливает молчание (нет вывода и нет шагов дольше настраиваемого срока, по умолчанию 10 минут), а не общая длительность; в чате предупреждение о долгой стадии.»

> «Зависимости worktree: если `node_modules` (или аналог) есть в основной копии и lock-файлы совпали, копировать копией (`cp -c` / `--reflink` там, где умеет файловая система), иначе прежний путь; на Windows путь остаётся прежним и это записано.»

> «После `finish` один лёгкий агент выбирает из `concerns`, повторных сбоев и отклонённых ревью не больше N (по умолчанию 5) уроков и дописывает их в `.autopilot/lessons.md`; при `init` следующей сборки файл читается исполнителем как короткий список (до 2 КБ, старое выпадает).»

> «Профиль проекта: команды сборки и тестов, стек и подводные места одной страницей, обновляется при `finish`, если изменились.»

> «Пользователь видит файлы и может удалить урок; ничего не пишется вне `.autopilot/` и `AGENTS.md`; секретов и путей вне проекта в уроках нет (проверка `check`).»

> «Любых изменений шлюзов, слепоты приёмки, подписей, guard, правил Opus и Fable.»

## Критерии приёмки

- [ ] `ap.py ticket NN bundle` печатает одним выводом хвост упавшей проверки (`tk["lastCheck"]`, пишется в `land` при красной проверке) и открытые замечания таска; тест на оба в одном выводе
- [ ] `silence.silent_agents` находит файл без изменений дольше срока и не находит недавно менявшийся; срок из `AUTOPILOT_SILENCE_SECONDS`, по умолчанию 600; `ap.py silence` даёт код 3 при тихом агенте; `ap.py stage` предупреждает о стадии дольше 60 минут
- [ ] `worktrees.link_deps`: lock-файлы совпали → копирует (на Linux/macOS), не совпали → `skipped`, на Windows → `skipped: windows` (поведение записано в `docs/autopilot/worktrees.md`); ошибка копирования не роняет `prepare`
- [ ] `prompts/executor.md`: исполнитель запускает только тесты своих изменений, полный набор гоняет `land`; читает `.autopilot/lessons.md` и `profile.md`, если они есть
- [ ] `phases/5-parallel.md` и `phases/9-lessons.md` описывают параллельные проверки и запуск лёгкого агента уроков после `finish`; оба в `SKILL.md`; `test_text_split` зелёный без повышения порога
- [ ] `lessons.render` режет до 2048 байт, новое первым; на пустой истории возвращает пусто; `lessons drop N` удаляет урок, а удалённая вручную строка не возвращается; `lessons.check_text` отказывает на секрет и на абсолютный путь вне проекта
- [ ] `ap.py lessons candidates` берёт из `concerns` и тасков с `retries`/`repairs` > 0, не больше `--max` (по умолчанию 5)
- [ ] `ap.py profile refresh` пишет `.autopilot/profile.md` и не пишет повторно, если текст не изменился; `finish` вызывает его и печатает подсказку про `phases/9-lessons.md`; `init` печатает число строк уроков, если файл не пуст
- [ ] Каждый новый модуль `ap.py` добавлен во все харнессы тестов, копирующие `ap.py`; полный `python -m unittest discover -s tests` зелёный
