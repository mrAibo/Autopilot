# Спецификация: Autopilot — дешевле, быстрее, удобнее (волны 1–3)

## Задача

Сборка платит в основном за перечитывание контекста: субагент обычного прогона стартует с 82–83 тыс. токенов вместо 8–13 тыс., оркестратор живёт на 224 тыс., хвост сборки (ревью, ремонт, приёмка) стоит почти как исполнители. Плюс первое знакомство: 22 строки `cp`, три отдельные предполётные команды.

## Решение

Субагенты обычного прогона идут на лёгких профилях; `ap.py` сам подсказывает, когда чат пора сменить; разовые команды-генераторы и посадка таска делаются одной командой без лишних ходов; текст обычного пути короче; инструменты ставятся и проверяются одной командой; у каждого субагента в отчёте есть модель; второй круг слепой приёмки проверяет только расхождения.

Эта сборка — волны 1–3 брифа (R01–R10) и две правки учёта расхода из «Дополнений» (G01, G02). Волны 4–6 (R11–R21) — следующей сборкой, по ответу пользователя.

Общие условия (R0001–R0003, R0006): шлюзы G1–G4, слепота приёмки, подписи, guard, запрет Fable не ослабляются; правила Opus не меняются; при переносе текста навыка не теряется ни одно правило; ничего из раздела 4 брифа («Чего в этой сборке нет») не делается.

## Решения по реализации

- Python, только стандартная библиотека; исходники — `skills/autopilot/tools/`, копии в `.autopilot/` обновляет `upgrade-tools`. Почему: так устроен проект.
- Постоянные профили строит новая функция в `agent_profiles.py` рядом с `definition`; `definition` и `prepare` строгого прогона не меняются. Почему: строгий путь подписан, трогать его нельзя (R0105).
- `chore` и `ticket land` — первый код в `ap.py`, который коммитит; общий помощник «коммит названных путей с трейлерами» один на обе команды. Коммит всегда `git commit --only -- <пути>`, без `git add -A` по всему дереву и без `git stash`. Почему: правило проекта.
- `bootstrap` и `doctor` разбираются в раннем ветвлении `main`, до чтения `state.js` и вне `locked_state()`; корень проекта — `--project` или текущая папка, а не место файла `ap.py`. Почему: из папки навыка `A` и `ROOT` указывают на навык.
- Порог подсказки контекста — переменная окружения, а не поле `state.js`. Почему: на `init` состояния ещё нет.
- Формат `state.blind` расширяется полем `rounds`, верхние `checked`, `matched`, `mismatches` остаются. Почему: их читают дашборд и `landing_problems`.
- `_ticket_at` (таск ставится любой роли) и остальные известные баги учёта не трогаются: пользователь взял только G01 и G02.
