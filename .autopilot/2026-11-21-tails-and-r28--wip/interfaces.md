## Правила проекта (из «Договорились»)
- Не менять шлюзы, слепоту приёмки, подписи, guard, правила Opus и Fable. Opus выключен, Fable не допускается; `dropped` ставит только пользователь; `main` в `origin` — только по слову.
- Исполнитель не коммитит (коммитит оркестратор через `ticket NN land`). `.claude/settings.json`, `ROADMAP-claude-code-2026-11.md`, `BRIEF-2026-11-orchestrator-spend.md` в корне не коммитить.
- Тесты, копирующие `ap.py` в харнесс, копируют каждый импортируемый модуль (`state_io.py`, `process_containment.py`, `run_log.py`, ...).
- Каждый баг — регресс-тест; `CHANGELOG.md` («Unreleased») ведёт **только таск 04**; остальные в нём ничего не правят.
- ADR этого прогона: `0030`–`0033`; уже существующий `0013` дополняется. Страница дашборда: одна разметка, шесть дизайнов, потолок шаблона 450 КБ.
- Один файл `ap.py` правят таски 02, 03, 04 подряд (волны 1, 2, 3); не параллелить.
- Каталог проекта в тестах и подпроцессах — временный; тест не читает реальный `~/.claude`.

## Границы, решённые в спецификации

**Сервер (T03)**
- `/.ap-ping?n=<nonce>` -> тело `hmac_sha256(serve.token, "autopilot-ping|<port>|<nonce>")` (hex). Клиент (`server_is_ours`) шлёт случайный nonce (≥16 hex-знаков) и сверяет `hmac.compare_digest`. Ответ без nonce, 404 или несошедшийся — сервер не наш, `serve()` его перезапускает.
- `log_message`: управляющие символы (код < 32 и 127), кроме обычного пробела, заменяются на `?`.

**`ask accept` (T02):** при `state["mode"] != "manual"` — `die("ask accept: только в режиме manual (сейчас <режим>); ...")`.

**`::имя` (T02):** совпадение `re.search(r"(?<![A-Za-z0-9_])" + re.escape(name) + r"(?![A-Za-z0-9_])", text)`.

**`doctor` (T02):** новая строка `git: версия X.Y` (или `git: версия не определена`), предупреждение `git ниже 2.22: ...` без кода 2.

**Расход (T04):** `spend_orchestrator`/`spend_subagents` не дописывают строку, если последняя строка той же роли/агента/модели с теми же числами (`input`, `output`, `cache_read`, `cache_write`, `turns`) уже есть.

**Shots (T05):** `python skills/autopilot/tools/shots.py --url URL --out DIR [--width N --height N]`; код 0 — файлы записаны, 2 — нет Chrome/Edge (строка причины); печатает пути, по строке на файл. Флаг `AUTOPILOT_BLIND_SHOTS=1` только в тексте `phases/8-final.md`; код приёмки не меняется.
