# Границы и правила проекта

## Правила проекта (из «Договорились» прошлых сборок — не пересматривать)
- Ключ подписи гейтов вне проекта (`~/.autopilot/gate.key`); Opus — только по подтверждению пользователя; Fable не допускается.
- Возврат упавшего таска и сдача с отказами — только цитатой пользователя.
- «ок, все три» (прошлая сборка) и «ок» (эта): из журналов читаются только суммы токенов, имя модели, `agentType` и id агента; текст сообщений, промпты и `description` не читаются и не сохраняются.
- Принятые пробелы `bash_gate` не чинить. `state.js` — только через `state_io.py`; файлы тасков — через `ticket_files()`; тесты, копирующие `ap.py` в харнесс, копируют `state_io.py`, `process_containment.py` и `run_log.py`.
- Только стандартная библиотека Python. Правила и команды — `AGENTS.md`.

## Границы, решённые в спецификации
| Единица | Владеет | Открывает | Прячет |
|---|---|---|---|
| `run_log.usage_by_agent(folder, since, until=None)` | чтением `folder/agent-*.jsonl` и `.meta.json` | `-> list[dict] | None`: на агента `{agent, agent_type, model, first_at, turns, input, output, cache_read, cache_write}`; `None` — папки нет/не читается; `[]` — агентов нет | формат строк Claude Code; пропуск битых строк, повтор `message.id` — последний |
| `run_log.KINDS["executor"]` | схемой строки | добавлены поля `agent`, `ticket` | — |
| `ap.spend_subagents(state, transcript=None) -> str` и команда `ap.py spend-subagents [--transcript PATH]` | записью строк `executor` по агентам; таск по окну `startedAt…finishedAt` тасков из `state` (ровно одно попадание, иначе нет) | одна печатная строка, не бросает; `finish` зовёт её после `spend_orchestrator` | вывод папки `subagents/` из пути журнала сессии |
| `ap.session_transcript()` | поиском журнала сессии | как раньше; при отсутствии точной папки — папка с наибольшим общим префиксом (≥100 знаков) и самым свежим журналом | усечение имён папок |
| `ap.compute_spend`, `run_log.summarize` | суммами | последняя строка на `agent`; `byTicket` берёт `ticket` из строки, иначе из имени профиля; строки журнала с `agent_type` вида `autopilot-…` отбрасываются, если у прогона есть строки хуков (без `agent`) | дедуп |

Швы для тестов: `usage_by_agent` — фикстурная папка во временном каталоге; `spend_subagents`/команда — подпроцессом `ap.py` в харнессе с `--transcript`; `compute_spend`/`summarize` — списками строк.
