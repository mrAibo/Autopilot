# 02 — Целевая проверка на land, полная перед ревью и в finish

**Требования:** R05, R06, R07
**Зависит от:** 01
**Зона:** `skills/autopilot/tools/ap.py` · `tests/test_land_targeted.py`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная
**Класс:** сложный
**Риск:** высокий
**Причина класса:** меняет путь «красный не садится» и два перехода (stage review, finish); ошибка ослабит защиту

## Что должно заработать

Если у таска есть строка `Целевая проверка: `…``, `land` гоняет её вместо полной; id таска попадает в `state["targetedLands"]`. `stage review` и `finish` гоняют полную проверку, если список непуст, и отказывают на красной (с именами упавших, формат T01), на зелёной очищают список. Нет строки — поведение прежнее.

## Из брифа, дословно

> «`land` гоняет целевые тесты таска на посадке (по зоне/файлам тестов таска, если они заданы в таске строкой «Целевая проверка: `…`»), а полную проверку — один раз перед ревью ветки (`stage review`) и в `finish`; сохрани прежнее поведение, если строки нет; не ослабляй защиту «красный не садится»»

## Разделы спецификации

Решение R05, R06, R07; `interfaces.md` «Границы» (T02); `notes.md`: `cmd_stage`, `cmd_finish`, `ticket_files`.

## Критерии приёмки

- [ ] `targeted_check_command(state, id)` читает строку из файла таска через `ticket_files`; регэксп допускает префиксы `*`, `-`, `>` и `**` вокруг названия; нет строки → None
- [ ] `land` с целевой строкой: гоняет её, условия те же (код 0, ≥1 тест, 0 упавших), полная не гоняется, `targetedLands` содержит id; без строки — прежнее поведение (полная), `targetedLands` не растёт
- [ ] `stage review` при непустом `targetedLands`: красная полная → отказ (код ≠ 0, переход не записан, имена упавших в выводе); зелёная → переход, `state["tests"]` обновлён, список пуст; при пустом списке полная не гоняется
- [ ] `finish` при непустом `targetedLands` — то же (красная → отказ); нет строки «Полная проверка» — предупреждение «! …», без запуска
- [ ] Красная целевая проверка не садится: тест на отказ и на отсутствие коммита; изолированный прогон и `repro` не затронуты
- [ ] Тесты `tests/test_land_targeted.py` на каждый пункт; весь набор зелёный
