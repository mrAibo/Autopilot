## Известные баги

- Кнопки: после первого клика с подписи пропадает название действия
- ADR `0015`: `ask accept` ограничен режимом `manual` только текстом фаз, CLI пускает его везде
- Закрыто правкой вне сборки (2026-11-21): старый `serve.answer.json` (теперь снимают `init`/`finish`/`reopen`), стирание непрочитанного ответа, двойной щелчок (600 мс), `[[[…` в теле, молчаливый срез 2000 знаков (теперь 413), фраза про `since` в ADR 0015. `finish`/`reopen`/`init` без своего теста
- Сервер, запущенный старым `ap.py`, отвечает 501 на POST до перезапуска (`finish` или новый `init`)
- `scheduler.py`/`commit_paths`/`gate_sign`: том без жёстких ссылок — пустой ключ не создаётся; брошенная заявка над целым ключом после ухода держателя остаётся до ручного удаления
- Слабые места прежнего: `::имя` ищется подстрокой; трейлер `Autopilot-Ticket` нужен git ≥ 2.22; «cannot import name» в выводе даёт ложный отказ `redproof`
- `lessons`: проверка путей ловит только `X:\`, `/Users/`, `/home/`; `lessons.md`, `drop`, `profile refresh` пишут без замка; `test_silence_without_any_transcript_is_not_all_alive` читает реальный `~/.claude`
- `worktrees.link_deps`: копия `node_modules` на macOS/Linux проверена только подменой платформы
- `chore` не принимает грязный `AGENTS.md`, запускать до правок
- Расход: поиск папки субагентов по префиксу может взять соседний проект; повторный `spend-orchestrator` дописывает строки
- Сервер: управляющие символы подделывают `serve.log`; `/.ap-ping` без nonce
