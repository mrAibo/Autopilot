## Известные баги

- `scheduler.py:91-92`: `ap.py schedule` не предлагает таск с зависимостью в `review`, хотя `ticket start` его пускает — одна строка при `not isolated` и тест
- `commit_paths`: старый путь переименования подхватывается только при дословном совпадении пути (каталог зоны — нет)
- `gate_sign`: при стойко занятой заявке `ensure_key` падает `OSError` даже над целым ключом (Windows, окно > 2 с); на томе без жёстких ссылок пустой ключ не создаётся
- Слабые места прежнего: `::имя` ищется подстрокой; трейлер `Autopilot-Ticket` нужен git ≥ 2.22; «cannot import name» в выводе даёт ложный отказ `redproof`

- `worktrees.link_deps`: копия `node_modules` на macOS/Linux проверена только подменой платформы
- `chore` не принимает грязный `AGENTS.md`, запускать до правок
- Расход: поиск папки субагентов по префиксу может взять соседний проект; повторный `spend-orchestrator` дописывает строки
- Сервер: управляющие символы подделывают `serve.log`; `/.ap-ping` без nonce
