## Известные баги

- `ticket NN land`: `--zone` заменяет зону таска без проверки; файлы, грязные до таска, считает «вне зоны» (нужен `--allow`); при параллельных тасках встаёт на красном соседа (увидено и в этой сборке); перенос файлов `git mv` в зоне оставляет старые пути в индексе — их приходится коммитить отдельно
- `commit_paths`: пути без `--literal-pathspecs`; переименование оставляет старый путь в индексе; проект в подпапке репозитория не поддержан
- `AUTOPILOT_CONTEXT_HINT` с не-ASCII цифрой роняет `init` и `stage`; `chore` и `land` запускают команду из `interfaces.md` через оболочку без белого списка; `bootstrap` и `upgrade-tools` копируют все `.py` навыка
- Расход субагентов: `_ticket_at` ставит таск всем ролям; поиск папки по общему префиксу может взять соседний проект; `state.spend` обновляется со следующей командой `ap.py`; расход оркестратора: строки старых моделей при смешении сессий, повторный `spend-orchestrator` дописывает строки
- `gate_sign`: гонка при старом пустом `gate.key`; копии без DPAPI читают блок `dpapi:` как сырой ключ
- Сервер: управляющие символы подделывают строки `serve.log`; `kill_orphans` → `processes()` зовёт PowerShell на каждую команду после `finish`; ответ `/.ap-ping` без nonce — слабый токен, вписанный вручную, подбирается офлайн
- `finish`: аттестации, дописанные хуком между чтением и обнулением, теряются (окно крошечное); после `reopen` совет «`plan-models --apply` вернёт профили» упирается в проверку «все таски pending» у сданных тасков
- Свод: повторный `start` после `ticket reset` без `class=` затирает класс таска на «не указан»; кэш истории принимает строку с `dir` и `startedAt`, но без остальных полей (сборка тихо выпадает из истории); временный файл кэша без pid
- `tools/run-tests.py`: `OK (expected failures=1)` читается как `failures=1` (в репозитории таких тестов нет)
- `refresh_dashboard`: не ловит `SyntaxError` из чужого `dashboard_upgrade.py`; столкновение имён копий в одну секунду
- Роутер: `env` как сегмент зоны чувствительное; `check-plan` не требует класс у `F<n>`
- `bash_gate`: не разбираются `setsid`, `ionice`, `flock`, `parallel`, `watch`; `curl -o`, `wget -O`, `tar -C`, `unzip -d` не глаголы записи; ложный отказ на абсолютный путь в `.autopilot/worktrees`
- `claude_attest.model_effort`: `agent_type` без проверки на `..`
- Нет тестов: эскалация на занятого Sonnet-исполнителя и `retries=2`; `session_id`/`author`; плохой `agentsSig`; проверка символических ссылок при удалении профилей (на этой Windows ссылки создать нельзя)
- Opus: `route` и `agent-for` сами не отказывают Fable в профиле `opusAgents`; нет сообщения, когда файл профиля Opus-ремонтника не найден
- Хук git: ложный отказ на `git log --grep git stash`; журнал: пути `/tmp/`, `/mnt/c/`, UNC не заменяются; `tests --seconds` принимает nan/inf
