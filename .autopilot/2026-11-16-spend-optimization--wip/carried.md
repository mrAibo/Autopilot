## Известные баги

- `gate_sign`: при старом пустом `gate.key` одновременный запуск из многих процессов в части прогонов даёт два ключа или читателя без ключа (свежий и полный ключ в порядке); копии без DPAPI в других проектах читают блок `dpapi:` как сырой ключ
- Сервер: управляющие символы в строке запроса подделывают строки `serve.log`; удалённый `serve.token` даёт 403 до перезапуска; неверный `?t=` показывает общую ошибку и опрашивает 403 вечно, а не подсказку про `ap.py url`
- `refresh_dashboard`: не ловит `SyntaxError` из чужого `dashboard_upgrade.py`; копия в tmp называется slug-метка-хеш — два обновления одного текста в одну секунду сталкиваются; `upgrade-tools` не копирует новые файлы инструментов
- Роутер: слово `env` как сегмент зоны чувствительное (`.env.example`, `env.py`) — сознательно; `check-plan` не требует класс у `F<n>`; `uncertainty` постоянна; после обновления на живом полёте повторить `plan-models`
- `bash_gate`: не разбираются `setsid`, `ionice`, `flock`, `parallel`, `watch`; `curl -o`, `wget -O`, `tar -C`, `unzip -d` не глаголы записи; запись по абсолютному пути в `.autopilot/worktrees` отказывает ложно
- `claude_attest.model_effort`: `agent_type` без проверки на `..`
- `ap.py compute_history` читает все архивные `state.js` при каждой команде; `run_log` держит счётчик сбоев в том же каталоге, что журнал
- Нет тестов: эскалация на занятого Sonnet-исполнителя и `retries=2`; `session_id`/`author`; `.claude/agents/*.md`
- Opus: `route` и `agent-for` сами не отказывают Fable в профиле `opusAgents` (останавливает guard); нет сообщения, когда файл профиля Opus-ремонтника не найден; нет теста на плохой `agentsSig`
- Хук git: слово git ищется не только в позиции команды — ложный отказ на `git log --grep git stash`
- Журнал: пути `/tmp/`, `/mnt/c/`, UNC не заменяются на `[path]`; `tests --seconds` принимает nan/inf
- `claude-version`: печатает весь список проблем даже для исправленной версии; не находит `claude.cmd` на Windows
- «Итог»: колонки «ревью» и «приёмка» выводятся из статуса таска; строка тестов зелёная даже при упавших; заголовок героя «Сейчас» экранирует `&amp;` дважды
