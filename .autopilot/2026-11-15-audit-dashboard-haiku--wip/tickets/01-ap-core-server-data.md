## Что должно заработать

Проект в папке со скобками находит свои таски; сервер дашборда не отдаёт данные чужой странице; возврат этапа не раздувает минуты; сброс гейта из-за плана пишется в ленту понятной записью; снимок дашборда пишется надёжно; `state.js` получает `history`, `spend`, `logFailures`; `report-run` показывает по каждой модели долю сданных с первого раза, починки и токены на таск. Спецификация: истории 1–4, 7, 12, 19, 20, 26, 27; границы — `interfaces.md` (ap.py · пути и сервер, этапы, лента гейтов, история сборок, расход; report-run).

## Критерии приёмки

- [ ] `ticket_files(state, pattern)` — единственное место `glob` по тискам; все 8 прежних вызовов идут через неё; `grep -n "glob.glob(os.path.join(run_dir" skills/autopilot/tools/ap.py` ничего не находит
- [ ] Тест: проект во временной папке `[ACME] x`, команды `ap.py tickets`, `check-plan`, `ticket 01 accept-edit` находят файлы тасков (до правки — «в tickets/ нет файлов»)
- [ ] Сервер: `GET /state.js` с чужим `Host` → 403; без `?t=` → 403; с `Sec-Fetch-Site: cross-site` → 403; с верным `Host` и токеном → 200; `GET /dashboard.html` без токена → 200; любой другой файл каталога `.autopilot` (журнал, папка сборки) без токена → 403 (тест поднимает сервер в потоке и ходит `http.client`)
- [ ] Токен хранится в `.autopilot/serve.token`, переживает перезапуск `ap.py`; адрес, который печатает `ap.py`, содержит `?t=`; `init` добавляет `serve.token` в `.gitignore` (вместе с `serve.*`)
- [ ] Снимок дашборда пишется через `state_io.replace_with_retry`: тест с моком `os.replace`, бросающим `PermissionError` один раз, — команда завершается 0, файла `dashboard.html.tmp` нет
- [ ] Возврат этапа: `stages[i].segments` копит отрезки; тест — этап дважды открыт и закрыт: сумма минут по отрезкам равна сумме интервалов, а не «последний конец минус первый старт»; без `segments` старые `state.js` читаются как раньше
- [ ] Сброс гейта при смене плана пишет в ленту `{"reason": "plan-changed", "g": "G1|G2|G4"}`, без числовых полей; тест на запись после `check-plan` с изменённым таском
- [ ] `state.spend` (`byRole`, `byModel`, `byTicket`), `state.history` (до 20 прошлых сборок из архивных `state.js` и `run-log.jsonl`; битый файл пропущен), `state.logFailures` (число из `.autopilot/run-log.fail`, нет файла — 0) попадают в `state.js`; тесты на фикстурах, включая журнал без модели («не указана»)
- [ ] `report-run` печатает блок по моделям: число тасков, доля сданных с первого раза, число починок, токены на таск; строки без модели — «не указана»; тест на вывод
- [ ] `.gitignore` игнорирует `state.lock` в любом каталоге; `git check-ignore skills/autopilot/tools/state.lock` → 0
- [ ] `python -m unittest discover -s tests` зелёный; тесты, копирующие `ap.py` в харнесс, копируют и `state_io.py`, `process_containment.py`, `run_log.py`, `gate_sign.py`
