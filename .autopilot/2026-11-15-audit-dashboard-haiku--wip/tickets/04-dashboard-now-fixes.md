## Что должно заработать

Дашборд открывается на новой странице «Сейчас · Требования · Итог · Подробности», которая сама показывает нужное по состоянию сборки; старые темы остаются под «Ещё»; лента не пишет «undefined» и не выдаёт сброшенный гейт за пройденный; минуты этапов считаются по отрезкам; у сданной сборки нет «обновлено N ч назад»; служебные строки переведены на человеческий язык. Спецификация: истории 3, 4, 9, 10, 11, 13, 17; границы — `interfaces.md` (dashboard-template · страница по умолчанию; ap.py · этапы и лента гейтов — формат данных).

## Из брифа, дословно

> «при сбросе гейта из-за смены плана в ленту пишется запись без чисел, а дашборд рисует её обычным шаблоном» — R03
> «минуты этапа считаются по этим двум меткам» — R04
> ««обновлено N назад» в шапке рисуется и у сданной сборки» — R09
> «в теме «Классика» счётчик повторов и починок виден только у сданного таска» — R10
> «полоса этапов объявлена списком (`role="list"`), а её элементы — без `role="listitem"`» — R11
> «Одна страница, которая сама показывает нужное по состоянию сборки, вместо восьми переключаемых тем — пользователь не должен выбирать, куда смотреть» — R13
> «Человеческий язык вместо служебного — навык обещает, что пользователь не читает спецификаций» — R17

## Разделы спецификации

Истории 3, 4, 9, 10, 11, 13, 17; решения о дашборде в «Решениях по реализации»; `interfaces.md`. Правила проекта из «Договорились»: логотип в шапке и рейке; «Классика» держит старые цвета.

## Критерии приёмки

- [ ] Вид `now` — первый в `VIEW_IDS` и по умолчанию; четыре вкладки «Сейчас · Требования · Итог · Подробности» (на английском свои подписи в `I18N`); сохранённый пользователем вид из `localStorage` по-прежнему уважается
- [ ] «Сейчас» подбирает содержимое: ждёт ответа → закреплённая полоса с текстом вопроса сверху; идёт разработка → блок прогресса тасков (доску рисует таск 05; здесь — простой список); сдано → итог; тест на шаблон для трёх состояний
- [ ] «Итог» содержит Гант и итоговые карточки сданной сборки; «Требования» — матрицу требований (как в «Классике»/«Требованиях» сейчас); «Подробности» — пока места под модели, расход, проверки и историю (наполняет таск 06), без «undefined»
- [ ] Старые восемь тем доступны в переключателе под «Ещё» и работают как прежде; логотип в шапке и рейке на месте; в узком окне (менее 700 px) раскладка сама складывается в одну колонку (`matchMedia`)
- [ ] Запись ленты `reason: plan-changed` рисуется «Проверка сброшена: план изменился» (карточка гейтов — «сброшена»); в ленте и карточках нигде нет «undefined» и «NaN» — тест прогоняет состояние с шестью такими записями и ищет эти слова в отрисованной строке
- [ ] Минуты этапа = сумма `segments`; без `segments` — как раньше; тест: сумма минут этапов не больше длительности сборки на фикстуре с возвратом этапа
- [ ] У сданной сборки вместо «обновлено N назад» — «сдано <время>» во всех темах; у идущей — как раньше
- [ ] В «Классике» у таска `in-progress` с повторами или починками виден счётчик
- [ ] Элементы полосы этапов с `role="listitem"` в обоих местах (:1764, :2120 в прежней нумерации)
- [ ] Страница при загрузке `state.js` передаёт токен из `location.search` (`?t=…`); без токена (открыто через `file://`) работает как прежде
- [ ] `humanRoute(route)` заменяет «score=…; profile=…; high-risk=…» строкой вида «Sonnet, усиленный режим: таск трогает подписи и ключи»; коды G1–G4 убраны из основного текста; ни один ответ не длиннее одной строки оговорки; тесты на `humanRoute`
- [ ] `docs/autopilot/dashboard-views.md` описывает вид `now` и «Ещё»; `python -m unittest discover -s tests` зелёный
