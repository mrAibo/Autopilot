## Критерии приёмки

- [ ] Если подмена снимка для открытой страницы без верного токена не удалась (`tokenless_page` вернул `None`: нет маркеров `BEGIN`/`END`, `UnicodeDecodeError`, конец раньше начала, `/*STATE-END*/` внутри текста снимка), сервер отвечает 403 и не отдаёт файл как есть; тест это проверяет файлом без маркеров и файлом с `/*STATE-END*/` в теле снимка (находка 2, `ap.py` около 1006–1008, `tokenless_page` / `do_GET`)
- [ ] `tokenless_page` ищет закрывающий маркер так, чтобы `/*STATE-END*/` внутри данных снимка не срезал подмену не в том месте (последнее вхождение или экранирование при записи снимка в `write_snapshot`); токен-страница с таким снимком отдаёт `window.STATE=null` целиком
- [ ] Тест `test_init_stage_and_finish_output_have_no_token` способен краснеть: проверяет вывод `main()` для `init`, `stage` и `finish` **без** `--no-serve`, с подменой `recorded`/`http_ok`/`is_guarded_server`, и падает, если в `serve()` вернуть старый `page_url(port)` с токеном; имя теста соответствует тому, что он гоняет (находка 1, `tests/test_followups_token.py`)
- [ ] `refresh_dashboard` работает в живом проекте, где в `.autopilot/` нет `dashboard_upgrade.py` (его не копирует `upgrade_tools`, копируются только уже существующие файлы): модуль берётся из `<skillDir>/tools` (с проверкой `skill_dir_trusted(state)` для подписанного прогона), без `ModuleNotFoundError`; тест воспроизводит проект без этого файла (найдено живым запуском в этой сборке: «дашборд не обновлён из шаблона (ModuleNotFoundError)»)
- [ ] Весь набор `tests/test_followups_token.py` и `tests/test_ap_audit.py` зелёный
