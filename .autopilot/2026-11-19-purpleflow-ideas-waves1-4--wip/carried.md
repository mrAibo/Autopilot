## Известные баги

- `ticket NN review` держит таск в статусе `review`, и зависимый `ticket MM start` отказывает до `done`: точечное ревью фундамента останавливает следующую волну (в этой сборке ждали ревью)
- `ticket NN land` пропускает только файлы зоны: чужие новые файлы (`docs/adr/*`) нужно `--allow`, и в коммит они не попадают; при открытом блокере `land` отказывает — ремонт коммитится руками (`git commit --only`)
- `agent-for reviewer` не работает в обычном (не строгом) прогоне — зовётся `autopilot-reviewer` напрямую
- `commit_paths`: переименование оставляет старый путь в индексе; проект в подпапке репозитория не поддержан; `chore`/`land` запускают команду из `interfaces.md` через оболочку без белого списка
- Расход: поиск папки субагентов по префиксу может взять соседний проект; `state.spend` обновляется со следующей командой; повторный `spend-orchestrator` дописывает строки
- Сервер: управляющие символы подделывают `serve.log`; `kill_orphans` зовёт PowerShell; `/.ap-ping` без nonce
- `finish`: аттестации между чтением и обнулением теряются; после `reopen` совет про `plan-models --apply` упирается в проверку тасков
- Свод: повторный `start` после `ticket reset` без `class=` затирает класс; `refresh_dashboard`: столкновение имён копий в одну секунду
- Роутер: `env` как сегмент зоны чувствительное; `check-plan` не требует класс у `F<n>`; `bash_gate`: не разбираются `setsid`, `ionice`, `flock`, `parallel`, `watch`
- `claude-version`: список проблем и для исправленной версии, не находит `claude.cmd`; хук git: ложный отказ на `git log --grep git stash`
- `test_gate_sign` один раз упал в полном параллельном прогоне (гонка), отдельно зелёный
