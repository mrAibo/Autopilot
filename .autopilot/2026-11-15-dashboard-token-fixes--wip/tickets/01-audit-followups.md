## Что должно заработать

Страница дашборда без токена не несёт данных прогона; адрес с токеном печатается только по `ap.py url`; ключ `gate.key` создаётся без окна гонки; правила не противоречат `finish --by-user`; «Сейчас» и «Требования» компактны; маршрут таска выбирает оценка планировщика (`**Класс:**`, `**Риск:**`, `**Причина класса:**`), а не регулярные выражения по тексту; копия страницы обновляется из шаблона.

## Критерии приёмки

Тесты рядом с кодом: новые — в новых файлах `tests/test_followups_*.py`; существующие тесты, которые описывали удалённое поведение, обновить по смыслу истории, не ослабляя.

- [ ] `GET /dashboard.html` без `?t=` и с неверным `t` отдаёт 200 с `window.STATE=null` в теле; с верным токеном — со снимком; файл `.autopilot/dashboard.html` на диске не меняется (R01, истории 1, 3)
- [ ] По HTTP без токена страница показывает одну строку-подсказку на русском и английском, без `undefined` и ошибок в консоли; `file://` и HTTP с токеном работают как раньше (R01, история 2)
- [ ] Вывод `init`, `stage`, `ticket`, `finish` не содержит `?t=` и значения `serve.token`; `ap.py url` и голый `ap.py` печатают адрес с токеном; `ap.py url` без `serve.token` создаёт его (R02, истории 4–6)
