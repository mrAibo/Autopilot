# Границы и правила проекта

## Правила проекта (из «Договорились» прошлой сборки — не пересматривать)
- Ключ подписи гейтов вне проекта (`~/.autopilot/gate.key`), признак «прогон начат подписанным» — `$AUTOPILOT_HOME/runs/`; на Windows ключ под DPAPI (блок `dpapi:`), на остальных ОС файл.
- Opus — только по подтверждению пользователя (`ap.py opus approve --by-user`); Fable не допускается ни под каким написанием.
- Возврат упавшего таска и сдача с отказами — только цитатой пользователя (`reset --by-user`, `finish --by-user`).
- Лого остаётся в шапке и рейке дашборда. «Классика» держит старые цвета, остальные темы — палитру макетов. Страница «Сейчас» по умолчанию; восемь старых тем под «Ещё».
- Принятые пробелы `bash_gate`: `>|`, `case…esac`, `find -exec sh -c`, `perl -pi`, heredoc, подстановки `$(...)` — не чинить.
- `state.js` читается и пишется только через `state_io.py`; файлы тасков ищутся через `ticket_files()`; тесты, копирующие `ap.py` в харнесс, копируют `state_io.py`, `process_containment.py` и `run_log.py`.
- Только стандартная библиотека Python. Правила проекта и команды — `AGENTS.md`.

## Границы, решённые в спецификации
Единицы и швы (имена на английском, как в коде):

| Единица | Владеет | Открывает | Прячет |
|---|---|---|---|
| `gate_sign.ensure_key()` / `load_key()` | созданием и чтением `gate.key` | `ensure_key() -> Path`, `load_key() -> bytes|None` (сигнатуры не меняются) | способ атомарного создания |
| `ap.make_server` / `allowed()` / handler | выдачей страницы и данных по HTTP | `GET /dashboard.html[?t=]`; без верного токена страница отдаётся с `window.STATE=null` | вырезание снимка |
| `ap.page_url(port, with_token=True)` | сборкой адреса | с токеном только для `ap.py url` и голого `ap.py`; в строке состояния и `init` — `page_url(port, with_token=False)` | — |
| `ap.refresh_dashboard(state) -> str` | обновлением `.autopilot/dashboard.html` из шаблона | одна строка для печати, не исключение | `dashboard_upgrade.upgrade` |
| `model_router.assess_ticket(text)` | оценкой таска | те же `scores` (`algorithm, coupling, uncertainty, context, testing, risk`); сигнатура не меняется | разбор заголовков `**Класс:**`, `**Риск:**`, `**Причина класса:**`, зона |
| шаблон `VIEWS.now`, `reqBoard` | видами «Сейчас» и «Требования» | `UI.rbOkAll` (свёртка колонки «Принято») | — |

Швы для тестов: сервер через `make_server` + HTTP на порту 0; `ensure_key` через потоки/процессы; `assess_ticket` через текст таска; шаблон через jsdom-харнесс тестов `test_dashboard_*.py`.
