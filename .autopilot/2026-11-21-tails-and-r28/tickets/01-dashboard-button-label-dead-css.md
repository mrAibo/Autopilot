## Что должно заработать

После первого клика на кнопке подтверждения остаётся название действия и просьба нажать ещё раз. Из шаблона убран мёртвый CSS и JS (`.nowh`, `.ov3`, `.tl2`, `html[data-narrow]`), страница стала легче. Строка «план: N из M» проверена тестом во всех шести дизайнах.

## Из брифа, дословно

> «Кнопки: после первого клика с подписи пропадает название действия»
> «Мёртвый CSS `.nowh .ov3 .tl2` и `data-narrow` (~3 КБ) — убирать вместе с тестами»
> «Строка «план: N из M» на дашборде и отчёт не проверены в браузере»

## Разделы спецификации

Решение R01; Решение R10 + R11. Заметки `notes.md`: «Кнопка», «Мёртвый CSS».

## Критерии приёмки

- [ ] Подпись взведённой кнопки (ru и en) содержит и название действия (`act.label[kind]`), и «нажми ещё раз» / «click again»; тест это проверяет для четырёх видов ожидания
- [ ] В шаблоне нет селекторов `.nowh`, `.ov3`, `.tl2`, `data-narrow` и JS, который их ставит или читает; `grep` по шаблону пуст
- [ ] Тесты, проверявшие именно наличие этих селекторов, удалены или переписаны; остальные тесты дашборда (`test_dashboard_*.py`, `test_followups_dashboard.py`) зелёные
- [ ] Размер шаблона меньше прежнего и не больше 450 КБ
- [ ] Node-тест: при заполненном `planFact` (`done`/`total`) строка «план: N из M» (en «plan: N of M») видна в разметке каждого из шести дизайнов
- [ ] ADR `0017` и `0019`: строки про «долг» (мёртвый CSS) помечены как закрытые этой сборкой
