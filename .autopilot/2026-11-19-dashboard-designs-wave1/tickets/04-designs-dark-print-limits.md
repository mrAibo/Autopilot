# 04 — Дизайны «Пульт» и «Терминал», печать, потолок размера

**Требования:** R31, R31a, R31b, R31c, R31d
**Зависит от:** 03
**Зона:** `skills/autopilot/phases/dashboard-template.html` · `tests/test_dashboard_designs.py` · `tests/test_dashboard_views.py` · `tools/check-dashboard-browser.py` · `docs/autopilot/dashboard-designs/`
**Волна:** 4
**Ревью:** нет
**Модель:** обычная
**Класс:** обычный
**Риск:** обычный
**Причина класса:** два дизайна по макетам, печать и общий тест по шести; логика простая, но много правил CSS

## Что должно заработать

«Пульт» (бумага, лайм, жёсткие тени, тикер) и «Терминал» (CRT-фосфор, ASCII-шкалы) красят те же блоки; слоты `dxTicker` и `dxAscii` рисуются из состояния. Печать (`window.print`) читаема во всех шести. Один тест проходит все шесть дизайнов по пунктам брифа (контраст, нет внешних ссылок, размер ≤450 КБ, 44 px, reduced-motion, печать). Скриншоты шести дизайнов на 1440 и 400 px сохраняются (инструмент `tools/check-dashboard-browser.py`, если на машине есть Chrome).

## Из брифа, дословно

> «`prefers-reduced-motion`; кнопки и пункты списка не ниже 44 px; печать (`window.print`) читаема.»
> «Особые элементы дизайнов — тикер «Пульта», ASCII-шкалы «Терминала» … рисуются из `window.STATE`, блок без данных не рисуется и не оставляет пустой рамки.»
> «Размер шаблона: сейчас около 255 КБ; потолок после шести дизайнов записывается в тесте (предложение: до 450 КБ). Если не помещается, лишнее в дизайне режется, а не потолок поднимается.»
> «тест проходит по всем шести дизайнам и проверяет эти пункты автоматом там, где это можно (контраст по токенам, отсутствие `http`, размер); скриншоты шести дизайнов на 1440 и 400 px сохранены в `docs/autopilot/` или в папке прогона.»

## Разделы спецификации

Истории 11–15; «Уточнения» (печать, скриншоты); `interfaces.md` — «Слоты», «Тесты (швы)».

## Критерии приёмки

- [ ] `html[data-design="brutal"|"terminal"]` задают все общие токены по `03-brutal.html` и `04-terminal.html`; Терминал — `dark` (CRT-линии и виньетка через `body:before/after` только для него), Пульт — `light`; системные стеки, ни одного внешнего адреса
- [ ] `dxTicker(c)`: бегущая строка из этапа, готово/всего, тестов и времени; `aria-hidden`, пауза по hover/focus, без анимации при `prefers-reduced-motion`, скрыта при печати; без данных `''`. `dxAscii(c)`: шкалы этапов, требований и тасков, текстовые полосы с подписью и значением; без данных `''`. Фикстура `empty` не содержит `.dx-ticker` и `.dx-ascii`
- [ ] `@media print`: скрыты рейка, закреплённая полоса, тикер, кнопки; все `<details>` раскрыты через стиль содержимого, фон светлый, текст тёмный — тест проверяет эти правила по тексту шаблона
- [ ] `tests/test_dashboard_designs.py`: цикл по `DESIGN_IDS` проверяет у каждого из шести: все общие токены заданы; контраст ≥4,5:1 по токенам (у `both` — обе половины); нет `https?://`, `<link`, `@import`, `@font-face`, `fetch(`; есть `prefers-reduced-motion` и `@media print`; размер шаблона ≤ 450 КБ (константа в тесте, не поднимается: если не помещается — режется дизайн)
- [ ] `tools/check-dashboard-browser.py` снимает шесть дизайнов на 1440 и 400 px в `docs/autopilot/dashboard-designs/` (нет Chrome — выводит строку «не проверено: нет Chrome» и завершается кодом 0); если файлы получились, они в зоне таска; крупные файлы не коммитятся, если суммарно >3 МБ (тогда в папку прогона)
- [ ] `python -m unittest discover -s tests -p "test_dashboard_*.py"` зелёный, `python tools/run-tests.py` зелёный
- [ ] Тест «правило 520 px последнее» (`test_narrow_rule_is_the_last_in_the_css`) проверяет, что оно последнее среди правил по ширине, а не среди всех `@media` — `@media print` и `prefers-reduced-motion` могут стоять после
