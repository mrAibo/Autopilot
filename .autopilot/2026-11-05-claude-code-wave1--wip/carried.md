## Известные баги

- «Итог»: колонки «ревью» и «приёмка» выводятся из статуса таска и слепой приёмки, а не из данных ревью: могут показывать «пройдено» там, где этого не проверяли (`dashboard-template.html`)
- «Итог»: строка тестов зелёная даже при упавших тестах и расхождениях приёмки; полоса таймлайна считается по календарному времени, подпись по активному
- «Ресурсы»: колонка токенов у таска без записанных событий показывает «0» только у ожидающих без маршрута, у остальных «—»
- «Обзор»: Гант показывает 8 строк, остальное за «ещё» (случай ≥9 тасков тестом не покрыт); «обновлено N назад» в шапке считает бесконечно и в сданной сборке; нет заметок по таскам вне Ганта
- Подписи полос Ганта подбираются измерением в браузере (`gxFit`): на каждый `resize` без ограничения частоты; смена ширины без `resize` пересчитается при следующей отрисовке
- Тест «Классика ⊂ Обзор» сверяет только заголовки карточек; нет теста экранирования `skillVersion` и XSS новых блоков; порог «Компактный короче Классики» 0.6
- `dashboard_upgrade.py`: ошибка чтения файла выдаётся как «not valid JSON»; копия в `.autopilot/` не находит шаблон («Dashboard template was not found»), запускать из каталога навыка
- Запись в `state.js` и `.autopilot/` через Bash хук не ловит (только Write/Edit) — предел назван в `docs/autopilot/claude-code.md`
- `execution sequential-host` стирает запись подписи, но оставляет `gateMark`; запись подписи не атомарна — `ap.py:985,1586,2286,2311`
- `ap.py tickets` сбрасывает статусы сданных тасков, если файл таска изменился (в том числе окончания строк); восстановление пришлось делать через `state_io` (см. дорожную карту, A01)
- Не проверено в браузере: Chrome, Firefox, Safari (только Edge); `file://`; контраст 4.5:1 измерением; перетаскивание окна; тёмные и английские варианты «Таймлайна», «Требований», «Итога», «Качества» глазами
