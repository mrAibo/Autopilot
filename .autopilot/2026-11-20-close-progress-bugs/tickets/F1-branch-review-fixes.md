## Что должно заработать

## Из брифа, дословно

> «баги plan-fact record, land_check, blocker confirm»

## Критерии приёмки

- [ ] `prompts/review-checklist.md` и `prompts/review.md` требуют для вердикта «сделано» доказательство `файл:строка` (или `файл::имя`), а не «команду»; сообщение `plan-fact record` о пункте, понижённом до «не сделано» из-за доказательства, называет причину (тест на текст сообщения/concerns)
- [ ] `redproof` отвергает вывод с `SyntaxError`/`IndentationError` только когда это строка исключения traceback (`^\s*(SyntaxError|IndentationError)\b` в начале строки вывода); тест: красный тест, чьё сообщение assert содержит слово «SyntaxError» в середине строки, принимается; настоящая синтаксическая ошибка отвергается; коды 126/127/9009 и «Ran 0 tests»/«no tests ran» отвергаются по-прежнему
- [ ] В ADR 0027 записаны как осознанные: снятие `.github` из защищённых файлов в `test_speed_lessons`, проверка доказательства только по существованию пути (строка в файле не сверяется), невозможность исправить ошибочный `confirmed` (выход — новый блокер)
