**Причина класса:** новый CSS по макетам и чистые функции слотов от состояния, без хитрых алгоритмов

## Что должно заработать

Три светлых дизайна красят те же блоки: Отчёт (бумага, Georgia, штамп «Сдано»), Чертёж (синяя сетка, размерные линии), Бенто (пастель, кольцо). Слоты `dxStamp`, `dxDim` и кольцо `ringHTML` рисуются из `window.STATE`; без данных не рисуются и пустой рамки не оставляют. Выбор других дизайнов эти слоты не показывает.

## Из брифа, дословно

> «Текст не ниже 4,5:1 контраста в каждом дизайне и в светлой и тёмной теме там, где тема есть (Отчёт, Чертёж, Бенто светлые по природе: тёмного варианта не требуется, но и неправильного не должно быть); состояние всегда и цветом, и словом или значком.»
> «Нет внешних запросов, шрифтов и CDN; системные стеки; `prefers-reduced-motion`; кнопки и пункты списка не ниже 44 px»
> «Особые элементы дизайнов — … размерные линии «Чертежа», штамп «Сдано» «Отчёта», кольцо «Авроры» и «Бенто» — рисуются из `window.STATE`, блок без данных не рисуется и не оставляет пустой рамки.»

## Разделы спецификации

Истории 11–13; «Уточнения» (кольцо, состояние словом); `interfaces.md` — «Слоты», «CSS-дизайны».

## Критерии приёмки

- [ ] `html[data-design="editorial"|"blueprint"|"bento"]` задают все общие токены из `interfaces.md` по палитре макетов (`mockups/dashboard-2026/02-editorial.html`, `05-blueprint.html`, `06-bento.html`); шрифты только системные стеки; ни `http(s)://`, `<link`, `@import`, `@font-face`
- [ ] Контраст текста (`--tx`, `--tx2`, `--mut` на `--card` и `--bg`; `--on-*` на заливках состояний) ≥4,5:1 у каждого из трёх дизайнов — тест считает по токенам
- [ ] `dxStamp(c)`: штамп «Сдано» (en «Done») с датой `finishedAt` только у сданной сборки, у Отчёта показан, у остальных скрыт; `dxDim(c)`: размерные линии героя с подписью срока (минуты работы) только при наличии времени; `ringHTML`: кольцо доли готовых тасков, центр — проценты, без `tickets` не рисуется; фикстура без данных (`empty`) не содержит `.dx-stamp`, `.dx-dim`, `.ring` вообще
- [ ] Статус этапа, таска, гейта и проверки в HTML всегда несёт текст или значок, не только класс цвета (тест на фикстурах `running`, `finished`, `gated`)
- [ ] Кнопки и пункты списка (`summary`, `.vopt`, кнопки) ≥44 px в этих дизайнах (правило в CSS проверяется тестом)
- [ ] `prefers-reduced-motion` отключает анимации новых элементов
- [ ] Остальные `test_dashboard_*.py` зелёные: `python -m unittest discover -s tests -p "test_dashboard_*.py"`
