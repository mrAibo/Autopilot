## Что должно заработать

В шапке дашборда рядом с языком и светлой/тёмной темой есть выбор вида из шести тем: Обзор (по умолчанию), Таймлайн, Требования, Ресурсы, Итог, Классика. Клик перерисовывает страницу, выбор запоминается. В шапке и боковой рейке — логотип проекта.

## Из брифа, дословно

> «Давай сделаем возможность видоизменять вид дашборда. Например, на более информативные.»
> «Имеется в виду выбор theme»
> «Дашборд по умолчанию не совсем информативно. Надо сделать возможность менять ее на более лучшие информативные темы и сделать несколько на выбор для большего пользовательского опыта.»
> «Да, и не забудь вставлять в дешборд наш лого.»

## Разделы спецификации

«Решение» (таблица тем), «Оценка сложности и способ», истории 1–6, «Решения по реализации», `interfaces.md` единица A. Образцы — `reference.md` (Figma: переключатель видов, KPI-строка Токены / Работают сейчас / Рабочие копии / Повторы и починки, таблица маршрутов моделей).

## Критерии приёмки

- [ ] В шаблоне есть `VIEW_KEY = 'autopilot-view'`, `VIEW_IDS` из шести id, `VIEWS` с функцией на каждый id, `storedView()` (неизвестное значение и ошибка хранилища → `overview`), кнопки `data-view` с `aria-pressed`, `'data-view'` в `focusAttrs`; названия тем и подпись группы есть в `I18N.ru` и `I18N.en` с одинаковыми ключами
- [ ] Клик по `data-view` пишет в `localStorage` (в `try/catch`) и вызывает `render(CUR.lang)`; выбранная тема сохраняется после перезагрузки
- [ ] Тема `overview` (по умолчанию) на одном экране показывает: шапку состояния, KPI-строку (токены, работают сейчас, рабочие копии, повторы и починки), трек этапов, активные и готовые таски, шлюзы G1–G4, сводку требований и последние события; `timeline`, `requirements`, `resources`, `summary` показывают состав из таблицы спецификации; `classic` совпадает с прежней вёрсткой
- [ ] Для STATE «пустой» (нет тасков, требований, лога, токенов), «в работе» и «завершённый» все шесть тем рисуются без исключения; пустые блоки дают подпись «ещё нет», а не пустоту; длинные списки раскрываются через `data-more`
- [ ] Логотип: инлайн `<symbol id="ap-mark">` со знаком из `assets/autopilot-logo-light.svg`, класс `brandmark`, слово `autopilot` («auto» обычным, «pilot» акцентом) цветом из переменных темы; в обоих заголовках `.top .brand` (включая `bootFail`) и в `.rail-brand`; `class="logo"`, `const LOGO =` и ссылки на PNG не появляются; `tests/test_brand_assets.py` зелёный
- [ ] Переключатель тем в узкой панели (≈400 px) не ломает шапку (переносится или прокручивается)
- [ ] `tests/test_dashboard_views.py` (новый): проверки по строкам шаблона и, если есть `node`, исполнение извлечённого JS на трёх фикстурах STATE во всех темах; без `node` — `skipTest`. `python -m unittest discover -s tests -p test_dashboard_views.py` и `-p test_brand_assets.py` зелёные
