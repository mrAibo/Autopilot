## Что должно заработать

В любой из шести тем ссылки навигации ведут на существующие блоки, а переключатель тем доступен в узкой панели.

## Из брифа, дословно

> «Надо сделать возможность менять ее на более лучшие информативные темы и сделать несколько на выбор для большего пользовательского опыта.»

## Разделы спецификации

Истории 1, 2 и 5; «Решения по реализации» (переключение без перезагрузки).

## Критерии приёмки

- [ ] Ссылка «Перейти к содержимому» ведёт на существующий элемент в каждой из шести тем (в `requirements` и `resources` тоже: `id="mission"` либо якорь на `.cockpit-content`)
- [ ] Каждая ссылка боковой рейки (`#mission`, `#tasks`, `#models`, `#quality`) в каждой теме либо ведёт на существующий блок этой темы, либо не показывается; тест проходит все шесть тем на фикстуре STATE и проверяет это
- [ ] В узкой панели (~400 px) все шесть кнопок тем достижимы без горизонтальной прокрутки (перенос строкой) либо выбранная кнопка остаётся видимой после перерисовки; проверка в тесте — по CSS-правилу и, где возможно, по разметке
- [ ] Существующие тесты `test_dashboard_views.py`, `test_brand_assets.py` зелёные
