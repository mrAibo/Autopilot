    Расширение

    Добавить дизайн

    Переключатель читает designs.js. Новый концепт — это HTML-файл и один объект в реестре. Сборка не нужна, стили изолированы iframe.

    1. Скопируйте шаблон. _template.html → 07-my-design.html. Внутри уже есть снимок window.D и базовые блоки — меняйте CSS и разметку.
    2. Допишите объект в designs.js. Обязательные поля: id, no, name, tagline, file. thumb можно не указывать.
    3. Обновите dashboard.html. Карточка появится слева, превью подхватит файл. Никаких сборок и установок.
    
    
    Работает по file://: реестр — обычный JS, файлы — обычные HTML. Если дизайн использует общий снимок, скопируйте блок window.D из любого концепта или из шаблона.
