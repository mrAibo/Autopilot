# Autopilot — шесть дизайнов и переключатель

Один живой снимок `state.js` — шесть разных языков дизайна, searchable combobox и design deck. Добавление седьмого дизайна не требует сборки: HTML-файл + объект в реестре.

На снимке — сборка **№18 «Волны 4–6»** (`orchestrator-spend-waves-4-6`), сдана 17.11.2026 в 17:42:

- 11/11 требований, 10 тасков в 6 волнах, 1 072 теста, гейты G1–G4, слепая приёмка 11/11;
- 358 201 токен, 18 вызовов, 97 % из кэша;
- 2 ч 25 мин работы при 14 ч 39 мин на календаре (пауза 12 ч 15 мин не в счёт);
- 7 неблокирующих замечаний.

## Открыть

1. **`dashboard.html`** — переключатель: **combobox с поиском**, живое превью, ширины Fluid / 900 / 430, полноэкранный режим, добавление нового.
2. `index.html` — галерея и сравнение шести концептов.
3. `01-aurora.html` — «Аврора», тёмный стеклянный mission control.
4. `02-editorial.html` — «Отчёт», светлый печатный annual report.
5. `03-brutal.html` — «Пульт», нео-брутализм с тикером.
6. `04-terminal.html` — «Терминал», CRT-консоль с фосфорным зелёным.
7. `05-blueprint.html` — «Чертёж», технический blueprint с размерными линиями.
8. `06-bento.html` — «Бенто», пастельные карточки и мягкая геометрия.
9. `_template.html` — стартовый дизайн для нового концепта (снимок данных уже внутри).

Каждый дизайн самодостаточен: данные встроены, внешних запросов и шрифтов нет. Достаточно открыть файл двойным кликом.

## Как переключать

`dashboard.html` читает `designs.js` и держит каждый концепт в изолированном iframe — стили не конфликтуют.

- **Combobox в шапке:** начните вводить название, тег или номер; `↑` / `↓` — выбор, `Enter` — открыть, `Esc` — закрыть. Работает и мышью, и с клавиатуры, с `aria-activedescendant`.
- Дублирующий выбор — карточки в рельсе слева (шесть дизайнов, скролл).
- **Клавиши** `1`–`N` (по числу дизайнов), `←` / `→`, `F` — полный экран.
- **Ширина:** `Fluid` (по месту), `900` (панель), `430` (телефон).
- Состояние сохраняется в `localStorage`; ссылка: `dashboard.html?d=terminal&w=panel`, поиск с предзаполнением: `dashboard.html?q=term`.
- `?add=1` открывает инструкцию добавления, `?combo=1` — сразу открытый combobox.

## Как добавить свой дизайн

1. **Скопируйте `_template.html`** в `07-my-design.html`. Внутри уже есть снимок `window.D`, базовая сетка, таски, требования и замечания. Меняйте CSS и разметку; данные можно взять из любого из шести концептов.
2. **Допишите объект в `designs.js`:**

```js
{
  id: "my-design",
  no: "07",
  name: "Мой дизайн",
  tagline: "одна строка о характере",
  file: "07-my-design.html",
  // thumb: "shots/thumb-07.png", // необязательно
  accent: "#5cc8ff",
  tags: ["custom"]
},
```

3. **Обновите `dashboard.html`.** Combobox, счётчик и карточка появятся сами: файл подхватится в iframe, `accent` покрасит интерфейс, `thumb` станет превью. Без `thumb` карточка нарисует акцентный фон с номером.

Обязательные поля: `id`, `no`, `name`, `tagline`, `file`. `accent` и `thumb` необязательны. Никаких сборщиков, npm и сервера — реестр это обычный JS, поэтому всё работает и по `file://`. Если дизайнов станет много, рельса слева прокручивается, а кнопка «+» в шапке всегда под рукой.

Chrome и Edge открывают локальные iframe по `file://` (проверено). Если ваш браузер блокирует такие iframe, запустите в папке `python -m http.server 8000` и откройте `http://localhost:8000/dashboard.html` — тот же результат, только по HTTP.
