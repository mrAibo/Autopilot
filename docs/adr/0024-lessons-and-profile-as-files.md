## Контекст
После `finish` один лёгкий агент (`autopilot-explorer`, `cheap_read`) выбирает до N=5 уроков из `concerns`, повторных сбоев, блокеров и снятых вторым проходом. Исполнитель при `init` читает короткий список. Профиль проекта (команды, стек, подводные места) обновляется при `finish`. По R27c пользователь видит файлы и может удалить урок; ничего не пишется вне `.autopilot/` и `AGENTS.md`; секретов и абсолютных путей вне проекта в уроках нет. `state.js` читается и пишется только через `state_io.py`.

## Решение
- Уроки — `.autopilot/lessons.md`: строки `- ДАТА — текст`, новые сверху. Чтение — не больше 2048 байт (`LESSONS_LIMIT_BYTES`), старое выпадает при выводе. `add` принимает не больше `max_items` (по умолчанию 5).
- `.autopilot/lessons.md.seen` хранит хеши уже записанных уроков. Урок, удалённый пользователем, при повторном `add` не возвращается.
- `lessons.check_text` проверяет текст при `add` и весь файл по `ap.py lessons check` (код 1): секреты, абсолютные пути вне проекта, перевод строки.
- Профиль — `.autopilot/profile.md`, одна страница. `profile refresh` пишет файл, только если текст изменился; `finish` его вызывает.
- `state.js` для уроков и профиля не используется.

## Почему
- Отвергнуто: уроки в `state.js`. Пользователь не увидит и не удалит урок как файл, а запись идёт только через `state_io.py`.
- Отвергнуто: уроки в `AGENTS.md`. Это файл проекта, и без предела он растёт; ограничить 2 КБ там нельзя без вреда для остального текста.
- Отвергнуто: файл без `.seen`. Удалённый урок вернулся бы при следующем подборе из тех же источников.
- Отвергнуто: писать профиль при каждом `finish`. Повторная запись без изменений даёт пустой шум в истории файла.
- Отвергнуто: хранить уроки вне проекта. R27c запрещает писать вне `.autopilot/` и `AGENTS.md`.

## Последствия
- Исполнитель читает `lessons.md` и `profile.md` при `init` (`prompts/executor.md`); `init` печатает число строк.
- Обрезка до 2 КБ отбрасывает старые уроки молча для исполнителя, но файл на диске сохраняет их, пока `drop` или ручная правка не уберут.
- Решение о том, коммитить ли `lessons.md` и `profile.md`, этой записью не закреплено.
