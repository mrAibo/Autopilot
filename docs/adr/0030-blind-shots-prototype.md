# 0030. Скриншоты для слепой приёмки: прототип за флагом

Статус: прототип, выключен по умолчанию (2026-11-21).

## Контекст

Бриф R28a: «Визуальная проверка агентом в браузере. Вариант: слепая приёмка получает скриншоты от отдельного лёгкого агента с Playwright на свободном порту в worktree. ADR и минимальный прототип за флагом; по умолчанию выключено.» Слепой проверяющий (`phases/8-final.md`) видит бриф и репозиторий, но не страницу в работе: вёрстку он принимает на слово.

## Варианты

1. **Вариант брифа: лёгкий агент с Playwright на свободном порту в worktree.** Агент поднимает сервер сборки на свободном порту, снимает страницы Playwright и отдаёт картинки проверяющему. Плюсы: клики, ожидания, любые браузеры. Цена: Playwright — зависимость с загрузкой браузеров (сотни МБ), которой в проекте нет, а навык держится на одной стандартной библиотеке; ещё один агент в схеме «три субагента, один вопрос каждый» и его токены; worktree нужен только при изоляции таска, а к приёмке сборка уже слита. Риск: сеть и установка в чужом проекте, порт гоняется с другими процессами. Не берём для прототипа.
2. **Headless Chrome/Edge через subprocess (выбран для прототипа).** `skills/autopilot/tools/shots.py`: `--screenshot` готового браузера, поиск как в `tools/check-dashboard-browser.py`. `shots.py` берёт готовый `--url` (адрес или файл) и проверяет схему (`http`, `https`, `file`); `free_port` — вспомогательная функция, статику сам не поднимает. Цена: ноль зависимостей, один вызов. Риски: нет Chrome/Edge — код 2 и строка причины; один кадр без кликов; окно headless Chrome ужимается примерно до 500 px по ширине (обход — iframe, как в `check-dashboard-browser.py`).
3. **Без картинок (сейчас).** Ничего не меняется; вёрстка проверяется текстом и `check-dashboard-browser.py` в CI. Дёшево, но слепой проверяющий не видит, как выглядит результат.

## Решение

- Прототип — вариант 2: `shots.py` и абзац о флаге в `phases/8-final.md`. Файл копируют `bootstrap` и `upgrade-tools` как остальные `.py` навыка.
- Флаг `AUTOPILOT_BLIND_SHOTS=1` живёт только в тексте фазы; код приёмки (`ap.py blind`) не менялся. По умолчанию выключено: снимки не делаются.
- Слепота не ослабляется: картинки идут как часть репозитория, `spec.md`, `manifest.md` и таски проверяющему по-прежнему закрыты.

## Рекомендация

Оставить выключенным. Включать там, где результат — страница, и только когда есть Chrome/Edge. К Playwright (вариант 1) вернуться, если понадобятся клики и состояния страницы и проект согласится на зависимость; тогда отдельный ADR.

## Не проверено

Прототип не гонялся в CI с настоящим браузером; тесты подменяют поиск браузера.
