# Вид `bug` — сначала красный тест

Вид ставится при `init --kind bug` или `ap.py set kind=bug`; `mode` и `depth` не меняются, классы и риск роутера тоже (Opus и Fable от вида не зависят).

1. В плане **ровно один** таск воспроизведения: в файле `**Вид:** воспроизведение`, без зависимостей, первым. `check-plan` иначе отказывает.
2. Исполнитель пишет тест, который падает по причине бага. Затем оркестратор: `ap.py ticket NN redproof --command "<команда одного теста>"`. Код 0 — отказ «тест не красный»: тест не воспроизводит баг. Вывод с `SyntaxError`, `ImportError`, `ModuleNotFoundError` или `cannot import name` (нет функции или модуля) — тоже отказ «не по-настоящему красный»: сперва заглушка, потом тест на `AssertionError`. Иной код ≠ 0 пишет `tk["redproof"]`.
3. `ap.py ticket NN land` воспроизводящего таска без `redproof` отказывает; с ним вливает **без полной проверки** (красный тест — цель).
4. Остальные таски вливаются, когда воспроизводящий `done`; иначе `land` отказывает. Только это правило снимает `--by-user "<цитата>"` — слова пользователя, не оркестратора; остальные отказы `land` (пересечения, зона) цитатой не снимаются.
5. Фикс-таск доводит тот же тест до зелёного; полная проверка гоняется на нём как обычно.
