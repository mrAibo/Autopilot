# Phase 3 — Spec (digest)

Working digest of `phases/3-spec.md`. **Read the full text only if something below is not enough** (the depth-dimension table, the spec template, the coverage-check prompt verbatim).

`ap.py stage spec` → `.autopilot/<dir>/spec.md`. The user sees two lines.

- **Existing code is explored first:** one `autopilot-explorer` (a verified, permitted cheaper model; Astra/Fable never automatically) writes `notes.md` — where things live, conventions, run commands, **exact names** of entities/fields/functions to be touched. For Haiku/cheap tickets it also writes `context-pack.md` (excerpts + signatures, read-only material, no secrets/machine paths); executors read it first and the source for anything it skips.
- **`carried.md` after a landed run:** its «Изменено после сборки» goes to the explorer; its «Договорились» goes word for word into `interfaces.md` as project rules; a spec section that would break one is rewritten or put to the user in one line — never decided by you.
- **No reopened interview.** Unresolved → `placeholder`. One exception: a genuine fork the briefing missed (branches = different projects) — ask once, one line, with a recommendation; in full decide and record `ASSUMPTION`.
- **Depth pass — the brief is a silhouette.** Dimensions: first run, empty, wrong input, failure, interruption, growth, boundaries, aftermath. strict: only wrong input + failure where the requirement plainly breaks, no `A##` · normal: by judgement · deep: every dimension or explicit «не применимо». Each answer is an `R##.n` story with its own acceptance line; padding is as bad as skipping. Propose when the answer is the user's; decide craft (error text, retry, limits) and say so.
- **Marks:** `R##` brief (untouchable) · `R##.n` deepening · `G##` user's later words (untouchable) · `A##` new capability, **must name a parent `R##`** (orphan → cut), `A` stories never outnumber `R`+`G`, tickets closing `R` fly before tickets closing only `A` · `D##` only via `5-repair.md`.
- **Boundaries → straight into `interfaces.md`** under «Границы, решённые в спецификации»: per unit what it owns / exposes (English names, signatures) / hides; then the test seams (few, existing preferred). The spec keeps a pointer.
- **File:** small product (T0/T1) → short spec (Задача, Решение, Решения по реализации, Вне рамок, Открытые места). Otherwise: Задача · Решение · Истории (table `# | Метка | История | Приёмка`) · Решения по реализации (each with a «why» line, no paths/code) · Границы и швы → `interfaces.md` · Вне рамок · Открытые места (every `placeholder`). Use the vocabulary of `CONTEXT.md`/`GLOSSARY.md`/`docs/adr/`; say a contradiction out loud.
- **G2 before leaving:** (1) own pass: every row `open` → `in-spec` (section in «Где») or `deferred`; zero `open`. (2) independent coverage check: an `autopilot-reviewer` (`model`+`effort` in the call) gets **exactly** every `*-brief.md` oldest first + `spec.md`, never the manifest/conversation, told to open nothing else, no skills, no agents; finds brief items missing / half-covered / spec items not in the brief, one line each, no quality opinions. Act: missing/half → write; not in brief → attach to a parent `A##` or cut. Record: `ap.py coverage found=N fixed=N deferred=N --item "…"`. Prompt text: full file.
- **Showing it:** full/semi/interview — two lines (what is built, what deliberately not, where the file is), then go. **manual** — `ap.py ask spec`, show in full, wait for explicit «ок» (chat or `ap.py await`); silence is not agreement.
