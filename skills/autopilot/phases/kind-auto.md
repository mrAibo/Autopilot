# Слово «авто» — выбор вида работы

Если пользователь сказал «вид: авто» (или вид не назван и нужен выбор), оркестратор подбирает `kind` по тексту брифа:

| В брифе | Вид |
|---|---|
| «баг», «падает», «не работает», «сломалось» | `bug` |
| «рефакторинг», «перепиши без изменения поведения», «почисти код» | `refactor` |
| одна мелкая правка, до `QUICK_MAX_REQUIREMENTS` (3) требований | `quick` |
| всё остальное | `task` |

- `semi`: одним вопросом-подтверждением — «Похоже на <вид>. Так и ведём? (да / другой вид)». Ответ пользователя — решение.
- `full`: молча; в итоговый отчёт идёт строка `вид: <вид> (выбран по брифу)`.
- Затем `python3 .autopilot/ap.py set kind=<вид>`. Тексты видов: `kind-bug.md`, `kind-refactor.md`, `kind-quick.md`. Без слова «авто» вид по умолчанию — `task`, всё как прежде.
