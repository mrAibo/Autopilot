# Словарь

- **Сборка** — один прогон навыка `/autopilot` от идеи до готового проекта. Папка прогона: `.autopilot/<дата>-<slug>/`.
- **Таск** — единица работы исполнителя: файл в `tickets/` с зоной, требованиями и проверками.
- **Зона** — пути, которые таск вправе менять. От зоны зависят риск и маршрут.
- **Класс таска** — оценка сложности от планировщика: механический, обычный или сложный.
- **Гейт** — контрольная точка сборки (G1–G4); её прохождение подписано ключом.
- **Починка** — повторная работа над таском после красной проверки или ревью.
- **Дозапрос** — повторный запрос исполнителю после красной проверки.
- **Эскалация** — однократный переход таска с Haiku на Sonnet после первого дозапроса.
- **Пакет контекста** — файл `context-pack.md`, который разведчик готовит для исполнителя.
- **Отрезок этапа** — промежуток работы этапа от старта до возврата. Минуты этапа — сумма отрезков.
- **Haiku-таск** — таск, который по признакам (одна зона, до ~150 строк, проверяемые критерии) можно выполнить на Haiku.
- **Постоянный профиль** — один из четырёх профилей агентов с фиксированным именем (исполнитель, ревьюер, приёмка, разведчик), общий для всех прогонов папки; модель и усилие в нём не заданы, их передаёт вызов. _Избегать_: «профиль таска», «профиль прогона».
- **Команда-генератор** — команда проекта, которая переписывает заранее объявленные файлы (например, счётчик тестов в документации). Инструмент запускает её и коммитит только эти файлы. _Избегать_: «генератор», «скрипт генерации».
- **Посадка таска** — завершение готового таска одной командой: проверка зоны, полная проверка, коммит зоны и отметка таска сданным. _Избегать_: «коммит таска», «закрытие таска».
- **Второй круг приёмки** — повторная слепая проверка только тех требований, что первый круг отметил «частично» или «нет», и основного сценария; больше двух кругов не бывает. _Избегать_: «третий круг», «перепроверка всего».
